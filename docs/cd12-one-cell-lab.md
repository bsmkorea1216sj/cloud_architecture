# CD12-1 실습 단순화

검증 셀이 앞 셀의 `new_lab_schema`에 의존해 단독 실행 시 NameError가 발생했다. AWS 인증, 스키마·표 생성, 앱 정의, 자동 검증, 미리보기를 하나의 실행 셀로 통합했다. 준비 → 검증 및 웹앱 실행 → 정리로 교안과 노트북을 맞췄다. 정리 셀은 초기 상태에서 실행해도 안내하고 종료한다. IAM 토큰과 TLS 검증, 별도 검증 스키마는 유지한다.

검증: 전체 Python 구문, 빈 런타임의 정리 셀, PPTX XML과 Colab 앵커를 확인했다. 실제 AWS 연결은 검증하지 않았다.
