STEP 02 · PPT 11–16

AI 상품 자동 분류

상품 데이터를 읽고 미리 정한 카테고리에 분류하는 실습입니다. 없는 카테고리를 임의로 만들지 않고 애매하면 검수 필요로 표시합니다.

상품 ID상품명결과
DEMO-001면 반팔 티셔츠의류 / 상의
DEMO-002스테인리스 프라이팬생활 / 주방
DEMO-003욕실 청소 브러시생활 / 욕실
DEMO-004데님 청바지의류 / 하의
DEMO-005다용도 수납함⚠ 검수 필요

Codex에 입력할 요청문

Python 3.11로 CSV 상품 목록을 읽고 사전에 정의된 카테고리만 사용해 상품을 분류하는 프로그램을 만들어 주세요.
카테고리를 임의로 생성하지 말고 애매하면 review_required=true로 표시해 주세요.
결과를 CSV로 저장하고, 입력 검증, 오류 처리, 단위 테스트를 포함하세요.
외부 Cafe24 API는 호출하지 마세요.
완료 기준: 분류 사유(reason)와 검수 여부(review_required)가 출력되어야 합니다.

STEP 04 · PPT 19–20

GCP Cloud Run 배포 구조

백엔드 API를 Cloud Run에서 실행하는 과정을 이해합니다. 실제 배포는 실습 계정과 예산 설정이 준비된 경우 진행합니다.

GitHub→빌드·테스트→컨테이너→Cloud Run→HTTPS API
API 경로기능
GET /health서비스 상태 확인
POST /classify샘플 상품 분류
POST /products/preview등록 미리보기·검증

Codex 구현 지시 예시

FastAPI로 /health, /classify, /products/preview를 가진 교육용 서버를 만들어 주세요.
기본값 DRY_RUN=true로 외부 Cafe24 API는 호출하지 않습니다.
입력 검증, pytest 테스트, Dockerfile 및 Cloud Run 배포 안내를 포함하세요.
시크릿은 소스에 포함하지 마세요.
GCP 예산 알림은 비용을 자동 차단하지 않습니다. Cloud Run 인증, 최대 인스턴스 및 로그 보존을 확인해야 합니다.

STEP 05 · PPT 21–23

Cafe24 상품 등록 미리보기

기본 교육에서는 실제 쇼핑몰에 전송하지 않습니다. 분류·필수값 검증·중복 검사·승인 단계를 학습하는 모의 실습입니다.

검수 완료→등록 미리보기→승인→권한 확인→실제 등록(심화만)

교육용 미리보기 JSON

{
  "internal_sku": "DEMO-001",
  "product_name": "면 반팔 티셔츠",
  "category_label": "의류/상의",
  "review_status": "approved",
  "dry_run": true
}
위 JSON은 교육용 개념 예시이며 실제 Cafe24 API 요청 스키마가 아닙니다. 최신 공식 Admin API 문서의 엔드포인트·필수 필드·권한·호출 제한을 별도로 검증해야 합니다.
